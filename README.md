# Employee Sales Analysis (SQL)

**One-line:** Simple MySQL project demonstrating table design, referential integrity, and common queries (SELECT, JOIN, GROUP BY) to analyze employee sales.

## Files
- `employee_sales_analysis.sql` — schema + sample data + example queries.
- `README.md` — project explanation and run instructions.

## How to run
1. Open MySQL Workbench or mysql CLI.
2. Run `employee_sales_analysis.sql` (it creates the `company` DB, tables, and inserts sample data).
3. Run example queries in the file or use SELECTs to explore.

## Skills
- SQL: CREATE, INSERT, SELECT, JOIN, GROUP BY, HAVING, ORDER BY, DATE functions
- Database design: primary & foreign keys, referential integrity
